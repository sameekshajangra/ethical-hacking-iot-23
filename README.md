# IoT-23 Intrusion Detection System (IDS) 🛡️

This project implements an **AI-powered Security Operations Center (SOC) Dashboard** that detects IoT botnets (like Mirai) using the IoT-23 dataset.

## ✨ Features
- **Real-time AI Detection**: Uses Random Forest to identify malicious network flows.
- **Threat Topology Map**: Interactive Sankey diagrams linking attackers to victims.
- **AI Explainability**: Visualization of feature importance (why the AI made the decision).
- **Live Simulation Mode**: Streams traffic row-by-row for the "WOW" factor.

## 🚀 Quick Start
1. Run `./run.sh` to install dependencies and start the app.
2. Upload `presentation_demo_dataset.csv` via the sidebar.

[Streamlit Dashboard](http://localhost:8502)
